# Historial anterior de MySQL

Estos archivos se conservan para consultar o mantener una instalación MySQL anterior.
Están fuera del proyecto .NET y no forman parte del ensamblado de migraciones activo.
El directorio `TechnoSac.FullTank.Platform/Migrations` contiene únicamente PostgreSQL.
No ejecutar estos archivos sobre PostgreSQL ni importar su historial EF.
